# Taller 3 - Bases de Datos con Python

Proyecto desarrollado para el Taller 3 utilizando:

- Python
- SQLAlchemy
- Faker
- MySQL
- Git y GitHub

## Objetivo

Crear una base de datos MySQL y poblarla automáticamente
con 100.000 registros ficticios usando Faker y SQLAlchemy.

---

## Base de datos

Nombre BD:

```txt
taller_python
```

Tabla creada:

```txt
personas_andres
```

---

## Librerías utilizadas

Instalar dependencias:

```bash
pip install -r requirements.txt
```

---

## Ejecución

Ejecutar el proyecto:

```bash
python3 main.py
```

---

## Resultado esperado

El script:

- Crea tabla automáticamente
- Genera datos falsos
- Inserta 100000 registros
- Guarda datos en MySQL

---

## Resultado obtenido

El proyecto generó exitosamente:

- Base de datos MySQL
- Tabla personas_andres
- 100000 registros ficticios
- Inserción automática usando SQLAlchemy
